# Pump.fun Protocol Case Study: Dollar Distribution Analysis

## Executive Summary

Pump.fun has emerged as the dominant memecoin launchpad on Solana, generating over $870 million in cumulative protocol fees since launch.[^1] The platform's simple one-click token creation mechanism combined with an innovative bonding curve system has fundamentally transformed how tokens are launched on Solana.[^2] This case study analyzes how every dollar generated by Pump.fun is distributed across core recipients based on public data and platform mechanics.

## Protocol Overview

Pump.fun operates as a permissionless token launchpad that allows anyone to create and trade tokens using a bonding curve mechanism.[^3] The platform has processed over 5.6 million token deployments, with new tokens launching at a rate of 30,000-50,000 per day during peak activity.[^4] Unlike traditional token launches requiring technical expertise and capital, Pump.fun democratized token creation to a simple web interface requiring only 0.02 SOL (~$4) to deploy.[^5]

## Revenue Structure

### Token Creation Fees

The platform charges approximately 0.02 SOL per token deployment, providing a low barrier to entry while generating consistent revenue from the high volume of launches.[^9] During peak periods in late 2024, daily token creation fees alone exceeded $20,000 based on 1,000+ daily deployments.[^10]

**Distribution:**
- **Recipient**: Pump.fun platform treasury
- **Mechanism**: Flat fee per deployment
- **Revenue Share**: 100% to platform

### Trading Fees

Pump.fun implements a 1% fee on both buy and sell transactions during the bonding curve phase.[^11] This 2% round-trip cost represents the primary revenue driver for the platform, with fees automatically deducted from each transaction.[^12]

**Distribution:**
- **Recipient**: Pump.fun platform
- **Mechanism**: Automatic smart contract deduction
- **Revenue Share**: 1% buy + 1% sell = 2% round-trip

### Bonding Curve Graduation Fees

When a token reaches the ~$69,000 market cap threshold, it "graduates" from the bonding curve to Raydium DEX.[^13] The platform captures spread during this migration process, extracting additional value from successful token launches.[^14]

**Distribution:**
- **Recipient**: Pump.fun platform + Raydium
- **Mechanism**: Migration fee and spread capture
- **Revenue Share**: Variable based on bonding curve parameters

### MEV and Priority Fees

High-frequency trading activity on Pump.fun generates significant MEV opportunities, with validators and searchers extracting value from transaction ordering.[^15] The platform has implemented some anti-bot measures, but sophisticated traders continue to exploit timing advantages.[^16]

## Economic Flow Breakdown

### Token Lifecycle Economics

**Stage 1: Token Creation**
- Creator pays ~0.02 SOL creation fee[^9]
- Token minted with standard parameters
- Bonding curve initialized with predetermined supply[^41]

**Stage 2: Bonding Curve Trading**
- Price determined by constant product formula[^42]
- 1% fee on each buy and sell[^11]
- Market cap increases with purchases
- Price automatically adjusts based on supply/demand

**Stage 3: Graduation ($69k threshold)**
- Automatic migration to Raydium DEX[^13]
- Liquidity deposited to new pool[^33]
- Platform captures graduation spread[^14]

**Stage 4: Post-Graduation**
- Trading continues on Raydium
- Standard DEX fees apply (0.25%)[^32]
- Pump.fun no longer captures fees

### Fee Distribution Percentages

**Pre-Graduation (Bonding Curve):**

|-----------|-----------|

| Token Creators | 0% (token allocation only) |
| Traders | Bear 2% costs |
| Validators | Transaction fees only |

**Post-Graduation (Raydium):**
| Recipient | Fee Share |
|-----------|-----------|
| Raydium LPs | 0.25% per trade |
| RAY Stakers | Protocol revenue share |
| Validators | Transaction fees |
